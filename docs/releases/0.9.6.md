# Grengin API 0.9.6

## Changes

- Discovery exposes AI-provider categories from the version-specific catalog.
- Distribution indexes accept inline categories, with the category sidecar
  retained as a compatible fallback.
- The 0.9.6 compatibility index pins the tested AI-provider packages and auth
  templates to this backend release.

## Deployment

This release uses the existing database migration head; no new migration is
introduced relative to 0.9.5. Back up the database before upgrades. The release
targets a single backend instance. SSE transport is unchanged.

The experimental connector OAuth broker and other uncommitted local work are
not included. Existing dependency advisories and the unversioned provider-runtime
reload path documented in `../release-0.9.5-audit.md` remain open; this release
does not claim to fix them.
